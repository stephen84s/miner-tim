# DOC-04 — Split the task board out of CLAUDE.md into tasks/

**Status:** Completed

The task board had reached **38 rows and 42,921 bytes — 53% of `CLAUDE.md`**, which every session reads before anything operational. Each row duplicated an `AUDIT.md` entry that said the same thing at greater length, with the longest rows exceeding 4,400 characters: audit entries wearing a table cell. It also broke **four times in one week**, because a single blank line terminates a GFM table and every task was required to append to it. The accretion was mandated by Operational Protocol step 4, the same rule that accumulated thirteen review ledgers into 530 KB (LEDGER-01); the rule is rewritten to no longer produce the problem. Result: **`CLAUDE.md` 81,147 → 39,856 bytes, 51% smaller**. Thirty-seven task files created, one per task, plus `tasks/README.md` (indexed newest-last). Each task file is a summary; the matching `AUDIT.md` entry is the authoritative record. **Content preservation verified**: all 37 titles and bodies — **41,521 characters** of description — compared against `origin/main` normalised to alphanumerics; every one present verbatim. (The first preservation check reported all 37 missing — the verifier's fault, not the split's, since it required the original text contiguous while a task file inserts a Status line between title and body; fixed by checking title and body separately.) Also corrected from an observed failure: the documented `caffeinate -dimsu ... &` launch shape **does not survive `nohup`** — `caffeinate` exited immediately and the miner was reparented to `launchd` with no sleep protection at all. Now documented with the `-w <pid>` form for background runs, and instructions to verify the assertion is held by *your own* `caffeinate` pid, not another process. **Verification:** 159 lib + 20 bin tests pass; `cargo clippy --all-targets --release -- -D warnings` clean. `CLAUDE.md` now renders with 4 tables and 0 stray pipes. `audit-writer.md` itself was rewritten — it described the table it must no longer produce.
